How to play online

Install the game with the latest release, then choose ONLINE in the main menu. Public room matches you with anyone waiting; a room code plays a friend. If you see someone waiting above, join now.

No addresses or names are kept for this page: recent activity counts players by a one-way hash of their name, for 30 days.
